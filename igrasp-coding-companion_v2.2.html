b1 Prism Diagonal

Truth value: True

In a rectangular prism, the space diagonal connecting opposite corners is longer than any edge or face diagonal.

The property: which line is longer

Watch for on this conjecture

  • A fact about rectangular prisms in general earns General only when the participant says what the fact means for the property (which line is longer) (check 5c). The General 0 example below names the hypotenuse and stops at the verdict.
  • Following a line that is already in the figure ("going corner to corner") does nothing to the object, so it is not a doing.
  • For Logical, the participant must also say where the diagonal sits in the construction. "Connecting the corners makes a triangle" together with "the hypotenuse is the longest side," with no word on which line is the hypotenuse, leaves the middle step to the reader and is 0.

b2 Polygons and Angles

Truth value: False

The interior angles of any regular polygon always sum to 360 degrees.

The property: the sum of the angles

Watch for on this conjecture

  • A polygon named by its number of sides ("a triangle," "a hexagon") is a case specific enough to check even when the participant does not say "regular," and a loose estimate of the individual angles does not invalidate a case whose sum is in fact not 360.
  • A wrong remark beside a valid case does not undo the case: "a triangle is 180, and I don't think a square counts as a polygon" still offers a valid counterexample (Rule C4).
  • Adding up the stated angles of a shape is a calculation and can earn Operative ("a square has four angles of 90, so 360"), whereas stating the known total for a named shape ("a triangle is 180") is a fact from memory and does not. A calculation can earn Operative and Logical together.
  • A result still counts when it is wrong: the Operative 1 example below treats a six-sided polygon as two triangles, which does not matter for this code (Rule C1).

b5 Cone Cross-section

Truth value: False

A plane that intersects a cone can only create circular or elliptical cross-sections.

The property: the shape of the cross-section

Watch for on this conjecture

  • A vertical cut, whether the participant calls it down the middle, through the tip, or perpendicular to the base, gives a section that is neither a circle nor an ellipse, so naming the cut and a triangular result is a valid counterexample.
  • For Logical, the participant must say what the cut produces (a triangle, a straight edge); saying only that the result is not a circle or an ellipse shows that the conjecture fails without showing why. For Operative, by contrast, what the result is not ("not a circle or an ellipse") does count as a stated result.
  • An action said of every position at once is still an action ("wherever you cut it"). A plane that only "crosses through," with nobody acting and a result the conjecture already gives, repeats the conjecture and is 0 (the Operative 0 example).
  • A case named too loosely to check ("on the side more," with no resulting shape) is not a valid counterexample (Rule C4), so it earns nothing at step 2 (the General 0 example).

Does the participant say, in their own words, that the claim holds for every case, or give a specific reason about the kind of object the conjecture names (for example, triangles in general and not one triangle) and tie it to what the conjecture is about?

Coded 1

False. Like if that plane is like cut from the top, that the point to the end, and then you will get a triangle.

Why. Step 2: the conjecture is false, and a cut from the tip straight down, which gives a triangle, is a valid counterexample named clearly enough to check.

Coded 0

you could have it where it intersects, uh, your cone is like this. If it intersects, um, on the side more instead of a cross, then that's not gonna be a circular or an elliptical cross-section.

Why. Step 2 is not met: "on the side more" names no particular cut and no resulting shape, so the case is too loose to check, and nothing in steps 3 to 5 is offered.

Why. The case is constructed and the feature that makes it fail (a straight edge) is derived.

Coded 0

Why. The case is named and the outcome asserted, but the step that shows why (what shape results) is missing.

Operative

Coded 1

if you had a cone that goes up like this, then you had a plan that slices directly down, like through the tip of the cone [...] the cross-section would kind of be triangular because the base would be flat

b6 Trapezoid

Truth value: False

The diagonals of any trapezoid always bisect each other.

The property: whether the diagonals cut each other in half

Watch for on this conjecture

  • A counterexample must be named specifically enough to check (a trapezoid with one base much longer than the other). A description that mixes correct and incorrect claims, such as "an isosceles trapezoid bisects but others do not," or a "concave trapezoid," earns neither General nor Logical (Rule C4).
  • Naming a kind of case without saying what holds for it ("trapezoids that don't do that"), or saying only what a change should achieve without saying what the change is ("modify it so they don't bisect"), is not a doing.
  • An action with no stated result does not earn the code: "if you cut it in half," followed by "I have no idea," is 0 (the second Operative 0 example). Drawing the diagonals the conjecture describes does nothing to the figure either.
  • A reason tied to a different property (that the diagonals must cross somewhere) fails check 5c, because the conjecture is about whether they cut each other in half (the General 0 example).

How to work through a response

Read the whole segment once before coding anything. Then, for each form code, apply its test in the order written, apply any rule that fits the response, and compare the response with the examples on the conjecture's page. The examples show how the general rule applies; they never create a rule that holds for one conjecture only. If you are still unsure, take the code's default, which for all three codes is 0.

Validity codes

Intuition and Insight judge whether the content is correct, not the form of the justification (Rule C1). In the re-coding pass they are carried over from the first pass.

Intuition

What was the participant's first verdict, and was it correct?

Test, in order

  1. Find the first true/false verdict stated after the statement is read.
  2. If it is explicit, score it against the key: correct = 1, incorrect = 0.
  3. If no clean verdict is stated, infer the stance from a minimal cue ("yeah," "no," "I don't think so") or from reasoning that stays consistent to the end: correct = 1_inferred, incorrect = 0_inferred.
  4. Only if nothing can be inferred, code missing.

Value Use when

0 Incorrect verdict, stated explicitly at the outset.
1_inferred No clean explicit verdict, but a correct stance is inferable, from a minimal cue ("yeah," "no," "I don't think so") or from reasoning that stays consistent through to the end.

When in doubt

Infer before you settle on missing. Later changes of mind never alter the code; it is locked to the first verdict.

Insight

Is at least one correct, relevant mathematical idea present?

Test, in order

  1. Set aside the verdict; look at the ideas offered.
  2. Is there a valid idea, relationship, computation, or counterexample that bears on why the conjecture holds or fails? If yes, and nothing said about it is mathematically wrong, code 1.
  3. If the only content is a restatement of the conjecture, a wrong idea, or no idea, code 0.

When in doubt

Generous. If the spirit of a valid idea is there and the reasoning is not wrong, code 1, even when it is partial or loosely worded.

  • A correct verdict with no idea is 0.
  • A wrong verdict can still carry a correct idea (code 1).
  • Counterexamples are judged by Rule C4.

Form codes

General

Does the participant say, in their own words, that the claim holds for every case, or give a specific reason about the kind of object the conjecture names (for example, triangles in general and not one triangle) and tie it to what the conjecture is about?

Words used here

The conjecture is the printed statement the participant judges, and its claim is what it says is true. A case is one particular example, such as one triangle. The property is the one feature the conjecture is about (the list is in the table under this card). A word for every case is a word or phrase that makes a sentence apply to all cases at once, such as "any," "always," or "wherever."

Test, in order

  1. Ignore the conjecture read back. Ignore any part in which the participant reads the conjecture aloud or repeats its wording. Putting the conjecture in other words without adding anything, or explaining what its words mean, counts as repeating it. If nothing else is left, code 0.
  2. A counterexample. If the conjecture is false and the participant gives a valid counterexample (Rule C4), code 1.
  3. A case extended. The participant works through one case and then says, in any words, that the result holds for cases they did not try ("and that would apply to other triangles too"): code 1.
  4. The claim, said for every case. The participant says that the claim is so, or is not so, using a word for every case that the conjecture does not already use for the same objects (such as any, every, always, never, wherever, or no matter): code 1. Step G4 of the General tree has the full list and says when such a word does not count. Saying that something which differs from case to case makes no difference counts in the same way ("how far apart they are doesn't change the angles").
  5. A specific reason about the kind of object the conjecture names. Code 1 if a reason passes all three checks.
    • 5a. It is about the kind of object, not one occasion or one example. The participant does not need to say "all" or "every": a reason that speaks of the kind of object without picking out a particular one can pass ("the more sides, the bigger the angles get"). It fails this check if it is (i) told as something the participant did or saw, (ii) about one case only, or (iii) a doubt.
    • 5b. It names something specific. It names a part, a quantity, a dimension, or a relationship in the object, or it does a calculation step that uses no measurements of any one object ("you multiply by two three times"). Naming only the object or its overall shape fails.
    • 5c. It is tied to the conjecture. The reason itself says something about the property, or the participant says what the fact means for the property. A fact followed only by "so true" or "so false" fails.
  6. Otherwise code 0.

When in doubt

Strict. When you cannot tell whether a step or a check is met, treat it as not met.

  • Step 5 needs no word for every case: "you multiply by two three times, so it's eight" is 1.
  • "Wherever you cut it, it's a circle" is 1 by step 4, because "wherever" is the participant's word and not the conjecture's.
  • "A sphere is a ball shape, so it's a circle" is 0, because it names the overall shape and no part (check 5b).

Logical

Does the participant state a deductive chain?

Words used here

The premise is the starting fact. An intermediate claim is a middle step that follows from the premise. The conclusion is what the participant ends on, usually that the conjecture's claim is so or is not so. A chain is a premise, at least one intermediate claim, and a conclusion, in that order.

Test, in order

  1. List the steps the participant actually states: facts, definitions, computations, constructed cases, or if–then claims.
  2. Code 1 only if a stated premise produces an intermediate claim that is then used to reach the conclusion, so that the chain runs premise, intermediate, conclusion. The conclusion is never the intermediate, and the intermediate must say more than the premise.
  3. A valid counterexample also counts when the participant states the case and what it produces, not only that it fails (Rule C4).
  4. Otherwise code 0.

When in doubt

Strict. If you cannot point to a second step that depends on the first, code 0.

  • One reason followed by the verdict is a premise and a conclusion, not a chain, however apt the reason.
  • A correct image with no connecting steps is 0, and so is a case that is only confirmed ("I tried it and it worked").
  • Support from authority or appearance ("it's a theorem," "it looks right") is 0.
  • The conjecture's own given condition can serve as the premise when the participant derives from it a new fact that the statement does not mention and that leads to the verdict ("two pairs of angles are the same, so the last one would be the same as well").

Operative

Does the participant describe doing something to the object or with its numbers, themselves or as something anyone could do, and say what comes of it?

Words used here

A doing is something the participant describes carrying out; there are three kinds, listed in step 1. A report only tells what happened or what was seen, and nobody is described as doing anything to the object. The VR activity is what the participant performed or watched in VR for that conjecture (the usual one is in the table under this card).

Test, in order

  1. Find a doing. It is one of three kinds.
    • An action on the object, told with "I" (or "we") or "you" as the one who acts ("when I moved the vertex down"; "if you cut it through the tip"; "wherever you cut it").
    • A calculation that the participant carries out on stated numbers ("four angles of 90 make 360").
    • A case made up and followed to an outcome: the participant chooses a particular arrangement and says what then holds for it ("if two sides are the same length, together they're longer than the third").
  2. Check for a result. The participant says what the doing produces.
  3. Check that the result is about the conjecture's property, and not only what the conjecture tells you to start with ("the sides doubled").
  4. Code. If all three hold, code 1; otherwise code 0. On a VR conjecture (i1 to i6), enter 1_retold in place of 1 when the participant retells the VR activity with its result and the response has no other doing ("when I moved the vertex down, it met the base"). Enter 1 when the response has any other doing. Never enter 1_retold on a baseline conjecture (b1 to b6).

Values

Value Use when
1 The participant describes a doing (step 1), says what it produces (step 2), and that result is about the conjecture's property (step 3).
1_retold The same, on a VR conjecture, when the participant retells the VR activity with its result and the response has no other doing (step 4). It counts as 1 in every analysis, and it is marked so that the analysis can be repeated without it.
0 No doing is described; or a doing has no stated result; or the result is only about what the conjecture tells you to start with.

When in doubt

Strict about whether the three things are there, lenient about how well they are said. Start at 0 and move to 1 only when you can point to the doing, its result, and what the result has to do with the property, in the participant's words. A result still counts when it is said with uncertainty, loosely worded, revised, or wrong.

  • A report is not a doing. Each of these is a report: the object does it by itself ("the lines got closer"); the sentence is passive ("when it was moved"); someone else does it ("when he pulled it down"); the participant says only what they saw ("I saw a circle"). A report counts as a doing only when the participant goes on to reason from it in their own words, and it is then entered as 1.
  • Repeating the conjecture is not a doing. "If you double all the sides, it's eight times bigger" only repeats the conjecture and is 0. It counts as a doing if the participant adds a step or a result that the conjecture does not give ("doubling each one multiplies by two three times").
  • Retelling the VR activity is 1_retold. The participant tells it as what they did ("when I unrolled it, the width was twice the distance across"), or tells it with "you" and gives a result that the conjecture does not give ("when you pull the top down, it lies flat").
  • "Go from the top corner to the bottom corner" does nothing to the object; it only follows a line that is already there.
  • A conclusion drawn from one fact to another, with nothing done and nothing calculated, is not a doing. Judge it separately under Logical.
  • A calculation can earn Operative and Logical together.

Codes that are easily confused

  • Logical General

    A computation whose operands and result are stated ("each angle is 90 and there are four, so 360") is a chain even on a single instance, so it can earn Logical; whether that instance covers the whole class is a separate question, which General answers.

  • Logical Operative

    An action in VR retold with its outcome is Operative's matter, not Logical's, unless the participant adds steps. A conclusion drawn from one fact to another, with nothing done and nothing calculated, is not a doing; judge it separately under Logical. A calculation can earn both codes.

  • General Operative

    "When I moved it, the angles stayed the same" is General 0, because it is told as something the participant did (check 5a), but the same sentence can still earn Operative, because the two codes ask different questions.

  • Correctness Form

    The three form codes judge the kind of justification, not whether it is right, so any of them can be 1 when the content is mathematically wrong (Rule C1). The one exception is a counterexample, which must be valid (Rule C4).

Gesture codes

Both gesture codes concern representational gestures, and both are coded from the hands in the video, not from the speech (Rule C7). What separates them is whether the participant acts on the imagined object (agency) or sets it in motion (kineticity), which is Dynamic, or only depicts the object, which is Non-dynamic. Judge each gesture unit separately, then code the response: a code is 1 when at least one unit in the response qualifies for it. In the re-coding pass both gesture codes are coded again, from the video, under the v2.2 rules and in the same viewing as General, Logical, and Operative. Each conjecture page describes what a qualifying gesture might look like on that conjecture, with the reason.

Dynamic Gesture

Does at least one hand gesture depict an object, or part of one, undergoing a change?

Test, in order

  1. Identify the representational gesture units in the response (Rule C7), and ignore beats, self-touch, and incidental movement.
  2. For each unit, ask whether the participant does something to the imagined object or sets it in motion. The participant exercises agency on the object when the hand acts on it by turning, sliding, folding, stretching, compressing, cutting, or building it. The gesture adds motion to the object (kineticity) when the hand stands for the object, or a part of it, and moves as the object moves or changes. In either case the object is shown in one state and then another.
  3. If at least one unit does so, code 1; otherwise, code 0.

When in doubt

Code from the hands, not the speech. The question is what happens to the object, so a moving hand is not enough. If no unit acts on the object or sets it in motion, code 0.

  • Hands also move in order to depict. A hand that moves into position, outlines a shape, traces a line or arc that is already part of the figure, or points is showing the object as it is, and that unit is Non-dynamic.
  • Tracing is Dynamic only when the hand carries the object, or its moving part, along its path.
  • A unit that both holds a form and moves to change it is Dynamic (Rule C7).

Non-dynamic Gesture

Does at least one hand gesture depict an object, or part of one, held static?

Test, in order

  1. Identify the representational gesture units in the response (Rule C7).
  2. For each unit, ask whether the gesture only depicts the object or a part of it, with no agency exercised on the object and no motion added to it. Such a unit shows the object's shape, outline, size, or location, points to or holds a part, or traces a line or arc that is already part of the figure.
  3. If at least one unit does so, code 1; otherwise, code 0.

When in doubt

Code from the hands, not the speech. One qualifying unit is enough, and the number of units does not matter.

  • Both gesture codes can be 1 in the same response when separate units qualify.
  • A single unit that both holds a form and changes it is Dynamic only, although a separate static unit can still earn Non-dynamic.

Rules that apply across codes

C1

The codes are independent, although correlated.

No code requires another. Intuition and Insight judge whether the content is correct; General, Logical, and Operative judge the form of the justification. (Background, not needed for coding: the three form codes follow Harel and Sowder's three characteristics of the transformational proof scheme, namely generality, operational thought, and logical inference.) The gesture codes are coded from what is observed, independently of the verbal codes and of each other.

C2

One verbal code is generous and three are strict.

Insight is coded generously. General, Logical, and Operative start at 0 and become 1 only when the defining feature is genuinely present in the participant's own reasoning; when in doubt, they stay at 0.

A response whose only reasoning is the conjecture's own wording is 0 on all three. So is a response whose only reasoning is a formula, rule, or fact that the participant states from memory ("I remember," "using my knowledge from high school") without saying how it applies and without calculating with it, although such a response can earn Insight. If the participant gives up an earlier explanation, judge only the later one. You can tell this has happened when their answer switches or when they take the explanation back in words ("never mind," "actually, no"). This applies to every code except Intuition, which stays locked to the first verdict.

C3

Absence is 0.

Every code except Intuition is 0 when its feature is absent. Only Intuition may be coded missing, and only after an attempt to infer a stance has failed.

C4

Counterexamples must be valid.

A counterexample is valid only if it is mathematically correct, actually refutes the conjecture, and is named specifically enough to check (a cut through the cone's tip, or a trapezoid with one base much longer than the other), rather than left generic ("a shape where one line is steeper"). A polygon named by its number of sides ("a triangle," "a hexagon") is specific enough even when the participant does not say "regular," because the angle sum depends only on the number of sides. A cut through a cone that is called vertical, down the middle, through the tip, or perpendicular to the base is specific enough when the participant names a triangular result.

  • A valid counterexample earns General = 1. It also earns Logical = 1 when the participant states what the case produces (a resulting shape, sum, or crossing point, or a feature such as a straight edge or a corner), however loosely worded ("somewhat of a triangle," "it comes to a point"), and not only that the conjecture fails.
  • An incorrect counterexample, or one whose own description mixes correct and incorrect claims, earns neither General nor Logical.
  • Validity is judged on the case and what is claimed of it, not on the rest of the response. A wrong remark beside a valid case does not undo the case, and neither does a loose estimate along the way when the case does in fact refute the conjecture.
  • An argument that a false conjecture is false, with no particular case named, is not a counterexample. For General it is judged at steps 3 to 5 of General's card.

C6

Code only the participant.

The researcher's reading of the statement, prompts, and encouragement never count toward any code. When the participant's speech is labeled "Researcher," or the speakers run together, use the content to tell them apart, and do not credit a passage to the participant unless the attribution is clear. Speech after the researcher has moved on to the next statement belongs to the next response.

C7

Coding gestures.

Code only representational gestures, which depict geometric content such as a shape, a part, a location, or a transformation. Ignore beat gestures, self-touch, and incidental hand movement. A gesture unit begins when the hands leave rest, depicts the object or its transformation, and ends when the hands return to rest, and its onset and offset are treated as visibly recognizable. The gesture unit is what is judged, and the response is what is coded. Judge each unit separately, and code a gesture code 1 when at least one unit anywhere in the response qualifies for it, so the number of gestures does not matter. A unit is Dynamic when the participant acts on the imagined object (agency) or sets it in motion (kineticity), and Non-dynamic when the gesture only depicts the object or a part of it. If a single unit both traces or holds a static form and moves to change it, code that unit Dynamic. A separate static unit can still earn Non-dynamic. Each gesture unit counts toward one of the two gesture codes only: a unit judged Dynamic is not also counted as Non-dynamic. A response can still earn both codes when it has separate units of each kind. Determine gestures as far as possible from the hand movement and the action context alone, and rely on the accompanying speech as little as possible.

  1. Start. List the steps the participant actually states: facts, definitions, calculations, cases they set up, or if–then claims. The premise is the starting fact, an intermediate claim is a middle step that follows from it, and the conclusion is what the participant ends on; a chain is all three, in that order.

  2. L0 Does the participant give a counterexample?

    Yes → leads to go to L0a No → leads to go to L1

    Watch for. This branch applies Rule C4. A response without a counterexample goes straight to the chain test at L1.

  3. L0a Is the counterexample valid, that is, correct, actually refuting the conjecture, and named specifically enough to check?

    Yes → leads to go to L0b No, it is not valid → leads to go to L1

    Watch for. An invalid counterexample earns nothing itself, for Logical or for General (Rule C4). The participant's other reasoning is still judged, so go on to the chain test at L1.

  4. L0b Does the participant state what the case produces, such as a shape, sum, crossing point, straight edge, or corner?

    Yes → leads to Logical = 1 No, only that it fails → leads to go to L1

    Watch for. The result may be loosely worded ("somewhat of a triangle," "it comes to a point"). Saying only that the case fails, or that the result is not a circle or an ellipse, does not state what the case produces (the b5 page); such a response goes on to L1 and is checked for a chain like any other.

  5. L1 Does the participant state a starting fact (the premise), that is, a fact, definition, calculation, case, or if–then claim?

    Yes → leads to go to L2 No → leads to Logical = 0

    Watch for. Specific numbers do not make reasoning empirical: a calculation whose numbers and answer are stated ("each angle is 90 and there are four, so 360") supplies a step even on a single case. A stated step counts even when the participant credits it to memory or a lesson, whereas authority offered in place of steps ("it's a theorem") or appearance ("it looks right") is not a starting fact. Steps need not all be correct.

    Yes → leads to go to L3 No → leads to Logical = 0

    Watch for.

    Not a middle step:

    • the conclusion itself, which is the conjecture's claim or its opposite;
    • one reason followed straight by the verdict, however apt ("a sphere is round, so any cut is a circle");
    • a case that is only confirmed, with its outcome reported rather than worked out ("I pictured a square and it's 360");
    • a consequence that only says the claim again more loosely ("everything doubles, so the volume increases");
    • the verdict drawn straight from what the conjecture gives ("there are two pairs, so they have to be similar").

    A middle step:

    • a new fact that the participant works out from the conjecture's own given condition, which the conjecture does not mention and which leads to the verdict ("two pairs of angles are the same, so the last one would be the same as well");
    • a construction, when the participant builds the figure, places the target in it ("the diagonal is its hypotenuse"), and gives the fact that yields the conclusion. If the placement is not said, the middle step is left to the reader and the answer is No.

    • a report counts as a doing only when the participant goes on to reason from it in their own words, saying why the result came about or what it means for the property, and not only "so true" or "so false"; it is then entered as 1;
    • repeating the conjecture counts when the participant adds a step or a result that the conjecture does not give ("doubling each one multiplies by two three times").

  3. O2 Does the participant say what the doing produces? For a calculation or a made-up case, this is the outcome already stated, so do not look for a second one.

    Yes → leads to go to O3 No → leads to Operative = 0

    Watch for. A result may be the shape, size, position, or value that results; the direction of change ("more space left"); what the result is not ("not a circle or an ellipse"); or that the property changed or stayed the same. It still counts when it is said with uncertainty, loosely worded, revised, or wrong. These are not results: a list of possible outcomes; a doubt in place of an outcome ("who's to say where the midpoint is"); an action with no outcome of its own ("you could keep sliding it").

  4. O3 Is the result about the property shown below, and not only what the conjecture tells you to start with (i2: the sides are doubled; i3: the surface becomes a rectangle)?

    The step-through shows the chosen conjecture's property under this question; the table above lists them all.

    Yes → leads to go to O4 No → leads to Operative = 0

    Watch for. A result that is only about what the conjecture tells you to start with does not count ("the sides doubled"; "it formed a rectangle"). The result does not have to settle the conjecture, and a result worked out on a special case of the object counts too ("cut a square along its diagonal and you get two equal parts," for a conjecture about a trapezoid's diagonals, because a square is a special kind of trapezoid).

  5. O4 List every doing in the response. Is at least one something other than this participant's VR activity told again (a different action, a calculation, or a made-up case)? If unsure, answer No (1_retold).

    Asked only on a VR conjecture (i1 to i6). On a baseline conjecture (b1 to b6), a Yes at O3 is Operative = 1, because a baseline response is never 1_retold.

    Yes → leads to Operative = 1 No → leads to Operative = 1_retold

    Watch for.

    Enter 1_retold when the participant retells the VR activity with its result and the response has no other doing:

    • the retelling may be told as what the participant did ("when I moved the vertex down, it met the base") or with "you" ("in the VR, when you pull the top down, it lies flat");
    • words that follow the retelling and only give the answer or say the claim again are not another doing;
    • a case that was part of this participant's VR activity (for example, the plane just touching the sphere, for a participant who performed or watched that) is a retelling and not a made-up case. The video and the transcript show what this participant's VR activity was.

    Enter 1 when:

    • the response has another doing that would earn Operative by itself (it has its own result, and the result is about the property), that is, an action that was not part of the VR activity, a calculation, or a case made up and followed to an outcome;
    • a report counts because the participant reasons from it in their own words.

    Why it is marked:

    • 1_retold counts as 1 in every analysis; it is marked so that the analysis can be repeated without it.

Dynamic Gesture

  1. Start. Watch the participant's hands through the whole response, and find each representational gesture unit. A unit begins when the hands leave rest and ends when they return to rest (Rule C7). Judge each unit separately, then code the response. One qualifying unit anywhere in the response is enough for 1.

    Watch for. Code from the hands, not the speech. Answer "no" at D2 only after every unit in the response has been checked.

  2. D1 Does the response contain at least one representational gesture unit, that is, a gesture that depicts geometric content (a shape, a part, a location, or a transformation)?

    Yes → leads to go to D2 No → leads to Dynamic Gesture = 0

    Watch for. Beat gestures, self-touch, and incidental hand movement are not representational.

  3. D2 In at least one of those units, does the participant act on the imagined object (agency) or set it in motion (kineticity)?

    Yes → leads to Dynamic Gesture = 1 No → leads to Dynamic Gesture = 0

    Watch for.

    Acts on the object (agency):

    • the hand turns, slides, folds, stretches, compresses, cuts, or builds the object.

    Sets the object in motion (kineticity):

    • the hand stands for the object, or a part of it, and moves as the object moves or changes.

    Does not count, because the hand only depicts the object:

    • moving into position to show a shape, size, or location;
    • outlining a shape;
    • tracing a line or arc that is already part of the figure, unless the hand carries the object or its moving part along its path;
    • pointing.

    Before answering No:

    • check every unit in the response, because the code is 0 only when none of them qualifies.

Non-dynamic Gesture

  1. Start. Watch the participant's hands through the whole response, and find each representational gesture unit. A unit begins when the hands leave rest and ends when they return to rest (Rule C7). Judge each unit separately, then code the response. One qualifying unit anywhere in the response is enough for 1.

    Watch for. Code from the hands, not the speech. Both gesture codes can be 1 in the same response when separate units qualify.

  2. S1 Does the response contain at least one representational gesture unit, that is, a gesture that depicts geometric content (a shape, a part, a location, or a transformation)?

    Yes → leads to go to S2 No → leads to Non-dynamic Gesture = 0

    Watch for. Beat gestures, self-touch, and incidental hand movement are not representational.

  3. S2 In at least one of those units, does the gesture only depict the object or a part of it, with nothing done to the object and no motion added to it?

    Yes → leads to Non-dynamic Gesture = 1 No → leads to Non-dynamic Gesture = 0

    Watch for.

    Only depicts the object:

    • showing its shape, outline, size, or location;
    • pointing to or holding a part;
    • tracing a line or arc that is already part of the figure.

    Does not count here:

    • a unit that both holds a form and moves to change it, which is Dynamic only (Rule C7), although a separate static unit in the same response still counts.

    Before answering No:

    • check every unit in the response, because the code is 0 only when none of them qualifies.
